## MiniMax H3 — تنظیمات

اندپوینت: `POST https://api.minimax.io/v2/video_generation` · مدل: `MiniMax-H3`

| پارامتر | مقدار برای این پروژه |
|---------|----------------------|
| `resolution` | `768P` برای تیکِ تست، `2K` برای فاینال |
| `duration` | عدد صحیح ۴ تا ۱۵ — دقیقاً همان ثانیه‌ی پلان |
| `ratio` | `16:9` (در حالت image-to-video خودکار `adaptive` می‌شود و از تصویر پیروی می‌کند) |
| نرخ فریم | ۲۴ ثابت |
| صدا | استریو ۳۲kHz، همیشه تولید می‌شود |

**ساختار `content[]`:**

```json
{
  "model": "MiniMax-H3",
  "duration": 10,
  "resolution": "2K",
  "content": [
    { "type": "text", "text": "<< پرامپت ویدیوی پلان >>" },
    { "type": "image_url", "image_url": {"url": "..."}, "role": "first_frame" },
    { "type": "image_url", "image_url": {"url": "..."}, "role": "reference_image" },
    { "type": "image_url", "image_url": {"url": "..."}, "role": "reference_image" }
  ]
}
```

- نقش‌ها: `first_frame` · `last_frame` · `reference_image` · `reference_video` · `reference_audio`
- سقف‌ها: **۹ تصویر**، **۳ ویدیو** (هرکدام ۲–۱۵ ثانیه، جمعاً ≤۱۵ ثانیه)، **۳ صوت** — حداکثر **۱۲ فایل** در مجموع
- تصاویر: ۲۵۶ تا ۵۷۶۰ پیکسل، نسبت بین ۰.۴ و ۲.۵، حداکثر ۳۰MB
- بدنه‌ی درخواست ≤ ۶۴MB

**ترفندِ صرفه‌جویی:** اول با `768P` بگیر، تیک را انتخاب کن، بعد با اندپوینت regenerate همان را به ۲K ببر — ارزان‌تر از رندر مستقیم ۲K است.

**فریم اول + فریم آخر (کلید پلان S28):** دو تصویر با `role=first_frame` و `role=last_frame` بفرست. مدل بینشان را پر می‌کند. برای «ظاهر شدنِ» کنترل‌شده‌ی یک عنصر، بهترین ابزارِ کل جعبه‌ابزار توست.

## Seedance 2.0 — تنظیمات

| پارامتر | مقدار |
|---------|-------|
| مدت | تا ۱۵ ثانیه در یک رندر |
| رزولوشن | ۱۰۸۰p |
| نسبت | `16:9` برای مستر، `9:16` برای کات عمودی |
| رفرنس | تا **۹ تصویر**، **۳ ویدیو**، **۳ صوت** (ویدیوها ۲–۱۵ ثانیه، جمعاً ≤۱۵ ثانیه) |
| صدا | نیتیو، با لب‌سینک و سینکِ ضرب |

**قواعد پرامپت‌نویسی Seedance:**

1. اول رفرنس‌ها را معرفی کن: `@Image1 is the man, @Image2 is the location…`
2. بعد شات‌ها را شماره‌دار و با بازه‌ی زمانی بنویس: `Shot 1, zero to four seconds: …`
3. **۳ تا ۵ شات** در هر رندر — بیشتر از این کیفیت را می‌شکند.
4. اگر دوربین نباید تکان بخورد، **صریح بنویس** `camera locked off in every shot, no handheld`. پیش‌فرضِ Seedance حرکت دادن دوربین است.
5. برای سینک با آهنگ: فایل صوتیِ همان بخش را به‌عنوان `@Audio1` بده و بنویس `cut on the beat of @Audio1`.

**لب‌سینک دقیق برای پلان‌های [A]:** اگر H3 لب‌خوانی را دقیق درنیاورد، همان پلان را در Seedance با `@Image1` (فریم اول) + `@Audio1` (فایل ۱۵ ثانیه‌ای همان مصرع) بساز.

## LTX-2.5 — تنظیمات

| | Fast | Pro |
|---|---|---|
| رزولوشن | 720p / 1080p / 1440p / 2160p | 720p / 1080p |
| مدت | ۶ تا ۲۰ ثانیه | ۶ / ۸ / ۱۰ ثانیه |
| fps | 24 / 25 / 48 / 50 | 24 / 25 / 50 |
| نسبت | 16:9 و 9:16 (فقط همین دو) | همان |

- بالای ۱۰ ثانیه فقط در 720p/1080p و با ۲۴ یا ۲۵fps. با ۴۸/۵۰fps سقف ۱۰ ثانیه است.
- `generate_audio` را برای پلات‌های بی‌صدا **خاموش** کن (S01، S04، S12 …) — هم ارزان‌تر، هم تمیزتر.
- `duration: auto` را برای این پروژه استفاده نکن؛ طول باید دقیقاً با تدوین بخواند.
- `image` = فریم اول، `last_frame_image` = فریم آخر. برای S01 هر دو را بده تا حرکتِ نور دقیقاً کنترل شود.
- برای اسلوموشنِ نرم (S10، S11): با `fps: 48` رندر کن و در تدوین با ۲۴ پخش کن.
- LTX نسبت ۲۱:۹ ندارد؛ ۱۶:۹ بگیر و در گرید به ۲.۳۹:۱ کراپ کن.

## تدوین و گرید

**تایم‌لاین:** ۲۴fps · ۲۵۶۰×۱۴۴۰ (یا ۱۹۲۰×۱۰۸۰) · ماسک ۲.۳۹:۱ در خروجی

**ساختار نود در DaVinci Resolve:**

```
1  Balance        سفیدی و اکسپوژر هر کلیپ را یکسان کن (مهم‌ترین قدم)
2  LUT            «حالا» → Kodak 2383 خنک   /   «خاطره» → Fuji 3510 گرم
3  Curves         شدوها را به آبی، هایلایت‌ها را به کرم ببر
4  Sat            «حالا» اشباع ۶۵٪  /  «خاطره» اشباع ۹۰٪ با قرمزِ کم
5  Halation       Glow روی هایلایت‌ها، آستانه بالا، شدت کم
6  Grain          35mm برای «حالا»، 16mm درشت برای «خاطره»
7  Window         ویگنت خیلی ملایم، فقط ۵٪
```

**نکته‌ی کلیدیِ یکدستی:** خروجی سه موتور مختلف رنگ‌های متفاوتی دارد. قبل از هر کاری، از هر کلیپ یک فریم بگیر، همه را کنار هم بگذار و **فقط با نود ۱ (Balance)** یکسانشان کن. اگر این را نکنی، هیچ گریدی نجاتت نمی‌دهد.

**میکس صدا:**
- آهنگ اصلی: ۰ dB
- آمبیانس‌های انتخابی: −۲۴ تا −۳۰ dB — فقط این‌ها را باز بگذار:
  S10 (پروازِ گنجشک‌ها) · S14 (آب روی سنگ) · S18 (خنده‌ی بریده) · S23 (باران) · S26 (زنگ)
- بقیه‌ی پلان‌ها کاملاً میوت.
- صدای زنگِ S26 تنها صدایی است که اجازه دارد تا −۱۲ dB بیاید بالا.

**کات عمودی ۹:۱۶:** ری‌فریم دستی، نه خودکار. در پلان‌های [A] چهره را در یک‌سومِ بالا بگذار. پلان‌های S09، S12، S27 در عمودی کار نمی‌کنند — برایشان یا رندر جداگانه‌ی ۹:۱۶ بگیر یا از تایم‌لاین عمودی حذفشان کن.

**خروجی:** H.265، ۲-pass، ۱۰۸۰p = ۲۰ Mbps · ۱۴۴۰p = ۴۰ Mbps · AAC 320kbps.
